Interactive web client to test the Eato Meal Tracker API endpoints. Make sure your Laravel API is running at `http://localhost:8000` before using this client.

## Instructions

1. **Start the Laravel API** (if not already running):
   ```bash
   ./setup.sh
   # or
   docker-compose up -d
   ```

2. **Register or Login** to get an authentication token

3. **Use the forms below** to interact with the API
